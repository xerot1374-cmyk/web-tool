# Visual report format

For each issue, include:
- UTC timestamp matching the artifact filename
- page or route
- viewport
- state or scenario
- affected element or component when relevant
- short description of the visible problem
- reproduction context
- screenshot path
- focused screenshot path when element-level evidence was captured
- comparison reference if one was used

Frontend handoff should include:
- what was checked
- which issues were found
- where the evidence is stored
- UTC timestamp for each referenced artifact when relevant
- which pages and viewports need frontend attention

Do not include:
- speculative root cause
- suggested implementation details unless the user explicitly asks for them
